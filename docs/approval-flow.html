From pull request to merge

A developer submits with one command. CI scans and blocks the merge. A reviewer approves in a protected job, which signs the record and runs CI again.

The key, and how signed-approval decides

One ed25519 key pair. The private half signs, and only the approve job can read it. The public half lives on main, so the check needs no secret and a pull request cannot swap it.
